# RiverGuard

YOLO11s fine-tuned to detect plastic waste in rivers (bottles, bags, packaging, other plastic).
When the item count passes a safe limit it sends a Telegram alert with a photo. This public
demo only shows a preview of that alert.

This Space is deployed automatically from the GitHub repository, so edit the code there.
